## 3. 验收标准（可判定，逐条能打钩）

- [ ] B0 `python main.py` 启动，浏览器控制台 / webview 无 JS 报错；所有原有 DOM id 与函数入口仍存在（`rg` 核对关键 id 未丢）。
- [ ] B1 **逐模块真实操作回归通过**：
      - Illustrator：添加文件 → 导出 PDF / 最小化 / 文字转曲触发对应 worker（进度 + 日志更新）。
      - 条码：8 类均可选、生成预览、导出 SVG/EPS/位图、一键 Ai/Ps 调用成功（COM 项 Windows 实测）。
      - PDF：转换/编辑/转成PDF 各动作触发 `run_pdf_action`/`office_to_pdf`。
      - 图片：裁切 / 文字水印 / 改尺寸质量 / 7 格式导出各成功。
      - 设置：切主题、改强调色（色轮/滑块/hex）实时生效并保存。
- [ ] B2 **无死按钮**：界面上每个可点动作都接到真实 API，或明确是占位（视频=敬请期待；图片高级工具根本不出现）。
- [ ] B3 **PDF 菜单动作状态**：切换不同二级项时，主区「上传类型」与「将执行的动作」都正确切换；执行时用的是当前选中的动作，不是上一个。
- [ ] B4 现有 **21 项测试全绿**（`python -m unittest discover -s tests`）；Windows 上回归文件选择 / AI / Office→PDF / `build-windows.bat` EXE 启动。
