# 摸鱼工具箱 — v1 完成定义（DoD）

本文件是**这一个里程碑**的范围契约与验收标准。它回答一个问题：**"这一版做完 = 什么？"**

它不是 README，不是 AGENTS.md（那是仓库级、长期稳定的执行手册）。本文件是**里程碑级、每版重写**的。

> 状态：**已冻结（2026-07-21）。** 冻结后只有走 §5 变更流程才能改。

---

## 1. 第一用户 / 第一任务（锚点）

范围必须锚在一个真实的人 + 一件真实的事上，否则"完成"没有边界。

- 用户：包装设计师同事（日常做包装出图的设计师）。
- 任务 A（批量出图）：设计师接到包装订单后，把客户给的**整个文件夹里的一批 `.ai` 稿子**批量导成 PDF，发给印厂。
- 任务 B（条码）：设计师按商品条码（如 EAN-13 `6901234567892`）生成条码，导出为 EPS/SVG 放进设计稿。
- 验收样本集（冻结）：
  - 一个含 **≥5 个真实 `.ai` 文件**的文件夹（`tests/samples/ai/`，其中至少 1 个含文本以验证转曲）。
  - 一组 **固定条码编码清单**（`tests/samples/barcodes.txt`：覆盖 UPC-A / EAN-13 / EAN-8 / Code128 / Code39 各至少 1 条，含已知正确校验位的参照值）。

> 注：验收样本目录 `tests/samples/` 尚未落地，属 v1 收尾必备项，见 §3 A0。

---

## 2. v1 范围（封顶清单）

**做完 = 下列全部满足，且仅此。** 编号写死，天花板物理存在。

- [ ] 1. 批量导出 PDF：选定文件夹内的 `.ai` 端到端批量导出为 PDF，含进度、日志、可取消、连接丢失可提示。
- [ ] 2. 批量文字转曲：选定文件夹内的 `.ai` 端到端批量 outline，产物可正常打开。
- [ ] 3. 条码生成：UPC-A/EAN-13/EAN-8/Code128/Code39 输入即预览，导出 SVG/位图/EPS，编码与校验位正确，可在 Illustrator 打开。
- [ ] 4. Windows 免安装 EXE：PyInstaller 打包产物双击即用，`frontend`/`icon` 资源路径正确，无控制台窗口。

> 第 5 个念头来了 → 写进 §4 icebox，本版不碰。

## 3. 验收标准（可判定，逐条能打钩）

**禁止出现"完美/完整/像样/更好"这类不可判定的形容词。** 每条须能判成"过 / 不过"。
对 §1 的每一份冻结样本，跑一遍，逐条核对：

- [ ] A0 验收样本集已落地：`tests/samples/ai/`（≥5 个 `.ai`，含 ≥1 个带文本）与 `tests/samples/barcodes.txt`（含参照校验位）就位。
- [ ] A1 批量 PDF：样本文件夹每个 `.ai` 都生成对应 PDF，**数量一致、无遗漏**；随机抽 2 份能正常打开。
- [ ] A2 文字转曲：对含文本的样本转曲后，产物中**无残留可编辑文本**；版面元素位置不位移。
- [ ] A3 条码：对 `barcodes.txt` 每条生成，**导出的 EPS/SVG 能在 Illustrator 打开**，且条码下方数字与校验位**等于参照值**。
- [ ] A4 EXE：在**未装 Python 的干净 Windows** 上双击 EXE，任务 A、任务 B 各跑通一次，无控制台窗口、无缺资源报错。

**通过定义：A0–A4 全部打钩 → v1 完成，交付给 §1 的设计师同事，停手。**

> 这套"冻结样本 + 判据清单"就是本项目的 harness / 验收器。改任何实现后重跑它，立刻知道变好还是变坏。目前为手工执行；脚本化排在 icebox。
