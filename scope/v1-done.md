# 摸鱼工具箱 — v1 完成定义（DoD）

本文件是**这一个里程碑**的范围契约与验收标准。它回答一个问题：**"这一版做完 = 什么？"**

它不是 README，不是 AGENTS.md（那是仓库级、长期稳定的执行手册）。本文件是**里程碑级、每版重写**的。

> ⚠️ 状态：**草稿，未冻结。** 下面 §1 锚点与 §2/§3 均为接手时按现有代码推断的初稿，需与项目负责人确认真实第一用户/第一任务后再定稿并冻结。冻结前不作为强约束。

---

## 1. 第一用户 / 第一任务（锚点）

范围必须锚在一个真实的人 + 一件真实的事上，否则"完成"没有边界。

- 用户：`【待确认：谁在真实使用？例如你本人 / 某位包装设计师同事】`
- 任务：`【待确认】要在【什么时候】之前，用它把【哪一批真实的 .ai 文件 / 哪些条码需求】处理成【交给谁 / 干什么用】`
- 验收样本集（冻结）：`【待确认：列出真实输入清单——例如某文件夹下 N 个 .ai 文件、M 组真实条码编码，具体到数量与类型。这就是 harness 输入】`

> 如果这一节填不满，停手——先绑定一个真实任务再冻结。

**做完 = 下列全部满足，且仅此。** 编号写死，天花板物理存在。

## 3. 验收标准（可判定，逐条能打钩）

**禁止出现"完美/完整/像样/更好"这类不可判定的形容词。** 每条须能判成"过 / 不过"。
对 §1 的每一份冻结样本，跑一遍，逐条核对（以下为初稿判据）：

- [ ] A1 批量 PDF：样本文件夹每个 `.ai` 都生成对应 PDF，数量一致，无遗漏；产物能打开。
- [ ] A2 文字转曲：样本产物中无残留可编辑文本（转曲成功），版面无位移。
- [ ] A3 条码：对固定编码清单逐条生成，导出文件能在 Illustrator 打开，校验位与参照值一致。
- [ ] A4 EXE：在干净 Windows 环境双击运行，三大功能各跑通一次。

**通过定义：全部样本 × 全部判据 = 打钩打满 → v1 完成，停手。**

> 这套"冻结样本 + 判据清单"就是本项目的 harness / 验收器。改任何实现后重跑它，立刻知道变好还是变坏。目前 harness 尚未脚本化（见 §4）。
