# 摸鱼工具箱 — v1.1 完成定义（DoD）

本文件是**这一个里程碑**的范围契约与验收标准。它回答一个问题：**"这一版做完 = 什么？"**

它不是 README，不是 AGENTS.md（那是仓库级、长期稳定的执行手册）。本文件是**里程碑级、每版重写**的。

> 状态：**已冻结（2026-07-22）。** 冻结后只有走 §5 变更流程才能改。
>
> 前置：v1（`scope/v1-done.md`）的 §3 A0–A4 仍未全部打钩（EXE、macOS AI 自动化、样本）。v1.1 不取代 v1；v1 的开放项继续有效，二者并行推进。
>
> 范围形状备注：本版一次纳入三个功能模块（条码 / 图片 / PDF），偏宽——已向用户提示"先纵切一条再铺下一条"的风险，用户明确选择全纳入。实现时仍应逐模块纵切通到底，不并排半成品。
>
> 关键原则（用户定）：**功能结构稳定前不做整体视觉/导航改版**，新模块先按现有 UI 结构接入，视觉统一（迁移 `ui-preview.html`）留到功能稳定后统一做（见 §4）。

## 1. 第一用户 / 第一任务（锚点）

- 用户：包装设计师同事（沿用 v1 锚点）。
- 任务：设计师在日常包装出图中，用同一个工具箱：
  - A 生成标准条码 + 二维码，导出 EPS/SVG 进 Illustrator；
  - B 对包装用图做**裁剪 / 加水印 / 改尺寸质量 / 转格式**；
  - C 处理交付用 PDF：**页面转图片/文字、合并拆分旋转提页、Office↔PDF**。
- 验收样本集（冻结）：
  - 条码：`tests/samples/barcodes.txt` + 新增 `tests/samples/qr.txt`（含网址/纯文本/中文各 1）。
  - 图片：`tests/samples/img/`（≥3 张，含 1 张带透明通道 PNG、1 张大尺寸照片）。
  - PDF：`tests/samples/pdf/`（≥2 个 PDF，含 1 个多页、1 个含规整表格）+ `tests/samples/office/`（Word / Excel / PPT 各 1，供 Office→PDF 各独立路径）+ 1 张图片（供图片→PDF）。

## 2. v1.1 范围（封顶清单）

**做完 = 下列全部满足，且仅此。** 逐模块纵切通到底。

### 条码
- [ ] 1. **移除 JsBarcode 双引擎**：删 `frontend/vendor/JsBarcode.all.min.js` 引用（`index.html:97`）、`app.js` 的 `JsBarcode(...)` 预览（约 :525）、`api.py` 的 `export_generated_svg`（约 :317）。前端**只展示** Python 返回的 SVG。
- [ ] 2. **单引擎回归 + QR**：预览/SVG/EPS-AI 全走 `barcode_engine`；新增 QR（纯 Python `segno`）接入同一链路，前端类型列表出现 QR。

### 图片模块（窄切；Fabric.js 前端 + Pillow 导出）
- [ ] 3. 编辑：**裁剪 / 加水印（文字或图片）/ 调尺寸 / 调质量**，画布预览即所得。
- [ ] 4. 导出与格式转换（Pillow）：导出为 **PNG / JPG / WebP / BMP / TIFF / ICO / TGA**。

### PDF 模块
- [ ] 5. 纯 Python 跨平台（pypdf + pypdfium2 + Pillow）：**PDF→PNG/JPEG/TXT、合并 / 拆分 / 旋转 / 提取页、图片→PDF**。
- [ ] 6. **Office→PDF**（pywin32 COM 驱动 Word / Excel / PowerPoint）。前置与失败判据：
      - 前置：本机已安装对应 Word / Excel / PowerPoint。
      - 未安装时 UI **明确显示"需要安装 Microsoft Office"，不得静默失败**。
      - 套用 §11 平台守卫 + COM 清理；非 Windows 优雅降级提示。
- [ ] 7. **PDF→Office「尽力版」**（`pdfplumber` + `python-docx` / `openpyxl` / `python-pptx`；**不含 `pdf2docx`**，见 §4/§6）。写死口径：
      - PDF→DOCX：文本型 PDF 的文字**至少可选中、可编辑**；图片与复杂排版**允许错位**。
      - PDF→XLSX：**仅承诺固定样本中的规整表格**；无表格时给**明确提示**，不生成空表/乱表。
      - PDF→PPTX：定义为**"一页 PDF → 一页高清图片幻灯片"**，不承诺恢复可编辑对象。
      - UI 必须显著标注"仅提取内容，不保证版式与可编辑性"。

### 边界
- [ ] 8. **不做**：FFmpeg 音视频、视频下载、整体视觉/导航改版（均在 §4 icebox）。不引 bwip-js / Node。

> 第 N+1 个念头来了 → 写进 §4 icebox，本版不碰。

## 3. 验收标准（可判定，逐条能打钩）

**条码**
- [ ] A1 全仓库 `rg -i jsbarcode` **零命中**；`api.py` 无 `export_generated_svg`。
- [ ] A2 `barcodes.txt` 每条：前端预览 SVG 与 `export_barcode_svg` 落盘 SVG **同源**（均出自 `barcode_engine`），数字与校验位等于参照值。
- [ ] A3 `qr.txt` 每条：能预览 + 导出 SVG，手机扫码内容**等于输入**（含中文条）。

**图片**
- [ ] A4 对 `img/` 样本：裁剪 / 水印 / 改尺寸 / 改质量各做一次，导出文件能正常打开、参数生效（尺寸/水印可见）。
- [ ] A5 格式转换：同一张图导出全部 7 种格式成功；带透明 PNG 转 JPG 时透明处理有明确规则（白底或提示）。

**PDF**
- [ ] A6 纯 Python 组：多页 PDF→逐页 PNG（页数一致）、→TXT（有文字）、合并/拆分/旋转/提页各跑通、图片→PDF 能打开。
- [ ] A7 Office→PDF：**每条 COM 路径有独立样本**——Word/Excel/PowerPoint 各 1 个源文件，在装 Office 的 Windows 上各导 1 次 PDF 成功；**未装 Office 时 UI 显示"需要安装 Microsoft Office"、不静默失败**；macOS 侧返回明确"需 Windows + Office"提示。
- [ ] A8 PDF→Office（按 §2.7 口径判定）：
      - DOCX：文本样本转出后**文字可在 Word 选中编辑**；
      - XLSX：规整表格样本转出为可读表；无表格样本给出**明确提示**而非空表；
      - PPTX：多页 PDF 转出**每页一张高清图片幻灯片**，页数一致；
      - **界面确实显示"仅提取内容…"标注**（缺标注即 A8 不过）。

**回归**
- [ ] A9 `tests/test_barcode_engine.py` 增 QR 用例、全绿；`python main.py` 启动无 JS 报错，条码/图片/PDF 三页基本路径可用（COM 与 Office 相关项在 Windows 实测）。

**通过定义：A1–A9 全部打钩 → v1.1 完成。**
